# SupplyMatch — покупайте вместе, платите по оптовой цене

Сервис совместных закупок и доставки для малого бизнеса Тараза и Жамбылской области. Проект для хакатона.

**Сайт:** https://narutouciha431-sketch.github.io/supplymatch-mvp/
**QR-код для телефона:** https://narutouciha431-sketch.github.io/supplymatch-mvp/qr.html

## Идея

- Магазины объединяют заказы в одну партию и платят оптовую цену.
- Фермеры и частники из сёл, в том числе пожилые, получают покупателей. Если сами не справляются с сайтом, объявление за них размещает оператор.
- Одна машина забирает товар в сёлах и развозит по магазинам, поэтому доставка делится на всех.
- Сервис зарабатывает 5% с товара в закупке и плату за доставку.

## Что умеет сайт

- Вход и регистрация по номеру телефона и PIN-коду. Две роли: магазин и продавец.
- Совместные закупки: полоса сбора, срок, умный подбор по запросу («200 кг картошки»).
- Заказ проходит путь «сбор → собрано → в пути → получено». Каждый шаг делает нужный участник, после доставки магазин ставит оценку.
- Если партия не собралась в срок, сбор отменяется, деньги возвращаются.
- Калькулятор экономии и доставки, русский и казахский языки, крупный шрифт для пожилых.

## Как устроено

- `index.html` — весь сайт в одном файле, без сборки.
- Данные хранятся в Supabase (PostgreSQL). Правила доступа и все действия описаны в `supabase/schema.sql`.
- Без связи с базой сайт сам включает оффлайн-демо: данные хранятся в браузере. Включить демо вручную можно, добавив к адресу `?offline`.

Настройка базы с нуля описана в `supabase/НАСТРОЙКА.md`.
