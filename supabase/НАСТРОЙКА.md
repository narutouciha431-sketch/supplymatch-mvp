# Как подключить сайт к Supabase

Займёт около 10 минут. Без этих шагов сайт работает в оффлайн-демо режиме: данные хранятся только в браузере.

## 1. Создать проект

1. Зайдите на https://supabase.com и зарегистрируйтесь (можно через GitHub).
2. Нажмите **New project**.
3. Заполните поля:
   - **Name:** `supplymatch`;
   - **Database Password:** придумайте и сохраните;
   - **Region:** ближайший, например Frankfurt (Central EU).
4. Нажмите **Create new project** и подождите 1–2 минуты.

## 2. Выключить подтверждение email

Вход на сайте идёт по телефону и PIN, писем никто не получает. Поэтому подтверждение нужно выключить:

**Authentication → Sign In / Providers → Email → выключить «Confirm email» → Save.**

(В старом интерфейсе путь такой: Authentication → Providers → Email.)

## 3. Создать таблицы

1. Откройте **SQL Editor → New query**.
2. Скопируйте туда весь файл `supabase/schema.sql`.
3. Нажмите **Run**. Должно появиться «Success. No rows returned».

Скрипт можно запускать повторно: данные он не удаляет.

## 4. Скопировать ключи

**Project Settings → API** (или **Data API / API Keys**):

- **Project URL**, вида `https://abcdxyz.supabase.co`;
- **anon public** key, длинная строка, начинается с `eyJ...` (в новом интерфейсе бывает `sb_publishable_...`).

⚠️ Ключ **service_role** (или **secret**) никуда не вставляйте и никому не отправляйте. Он даёт полный доступ к базе.

## 5. Вставить ключи в сайт

В начале скрипта в `index.html` есть строки:

```js
const SUPABASE_URL="";
const SUPABASE_KEY="";
```

Вставьте между кавычками URL и anon-ключ. Можно просто прислать их Claude, он вставит сам.

## Проверка

- Откройте сайт. Жёлтой полосы «Нет связи с базой» быть не должно.
- Зарегистрируйте магазин на одном устройстве, а продавца на другом. Заказ магазина появится у продавца без перезагрузки.

## Полезно знать

- **Оффлайн-демо на защите.** Если пропал интернет, сайт сам переключится на демо-режим. Включить его вручную можно, добавив к адресу `?offline`, например `index.html?offline#home`.
- **Пауза проекта.** Бесплатный проект Supabase засыпает после долгого простоя. Перед защитой откройте панель Supabase и при необходимости нажмите **Restore**.
- **Демо-закупки истекают** через 1–6 дней после запуска `schema.sql`. Обновить сроки можно в SQL Editor:
  ```sql
  update public.pools set deadline = now() + interval '5 days', status = 'open'
  where id in ('g1','g2','g3','g4','g5','g6') and status = 'cancelled';
  ```
